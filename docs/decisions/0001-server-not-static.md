# 0001. Сервер и база, а не статический сайт

**Контекст.** Был вопрос: разместить на GitHub Pages. ТЗ требует, чтобы студент видел только свои данные, пароли не хранились открыто, а ключи ИИ не попадали в браузер.

**Решение.** Next.js с сервером + PostgreSQL на российском хостинге. Код – на GitHub.

**Почему.** Статический сайт не может проверить пароль и владельца заявки: всё, что в нём есть, видит любой посетитель. Ключ GigaChat в статике оказался бы в браузере. Заявка «сохраняется» только там, где есть база.

**Цена.** Нужен сервер (VPS/Amvera) и его оплата.
