# 0003. Drizzle ORM вместо Prisma

**Решение.** Drizzle + драйвер `postgres`.

**Почему.** Запросы выглядят как SQL – в ревью сразу видно условие владельца. Нет бинарного движка: меньше Docker-образ, проще сборка. Миграции – обычный SQL, свою миграцию с RLS легко положить рядом.

**Цена.** Меньше «магии» для связей; запросы пишем явнее.
