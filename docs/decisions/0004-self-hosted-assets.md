# 0004. Шрифт и ассеты – только с нашего сервера

**Контекст.** При сборке `next/font/google` упал: Google Fonts недоступен с машины разработки (как и в превью макетов). Сайт должен открываться из России без VPN.

**Решение.** Inter Tight (OFL) лежит в `public/fonts` (кириллица + латиница, вариативный), подключён через `@font-face` с `unicode-range` и preload. Никаких внешних CDN в рантайме.

**Цена.** Шрифт обновляем вручную.
