# 0005. Реалии ДВФУ и «живой» сид

**Решение.** Институты, направления, сетка пар (08:30, 10:10, 11:50…), часовой пояс Владивостока, аудитории в формате кампуса (D734) — как в ДВФУ. Люди, оценки и заявки — вымышленные. Переносы пар ставятся на текущую учебную неделю, заявки — относительно момента сида.

**Почему.** ТЗ разрешает адаптацию под свой вуз, это повышает «проработанность идеи». Жюри откроет кабинет в случайный день — данные должны выглядеть живыми, а не застрявшими в 23 ноября.

**Цена.** Сид перед показом нужно перезапускать (`npm run db:seed`), если прошло больше недели.
